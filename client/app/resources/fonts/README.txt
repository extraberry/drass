Fonts used by DRASS (design A):
- Inter (body text): included here (SIL Open Font License, see Inter-LICENSE.txt).
- Source Serif 4 (headings): NOT included. Download it free from https://fonts.google.com/specimen/Source+Serif+4
  (Download family, open the "static" folder) and copy SourceSerif4-SemiBold.ttf and SourceSerif4-Bold.ttf into this folder.
  Every .ttf / .otf file in this folder is loaded automatically at start-up. Until you add it, headings use Georgia.
