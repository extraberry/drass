# Database
Tables (see `server/app/models.py`): roles, users, departments, programs, research_categories, research_works (version, dup_key, current_status…), research_authors, keywords, research_keywords, revisions (metadata_snapshot JSON), files (storage_path relative; sha256), review_assignments (stage, reviewer, revision_number, status PENDING/DONE/CANCELLED), reviews (one per assignment), status_history, embeddings (float32 BLOB, model_name, dimension, text hash, status COMPLETE/FAILED/STALE/PENDING), notifications, sessions (token hash), audit_logs, activity_logs, system_settings.
Indexes: users.username (unique), research_works(title, year, program_id, department_id, category_id, adviser_id, current_status, dup_key), review_assignments(work_id, stage, reviewer_id), audit_logs(timestamp, action, user_id), activity_logs(timestamp, event_type).

**Roles table (`roles`)** holds exactly five rows: STUDENT, ADVISER, HEAD_LIBRARIAN, ADMIN, EXTERNAL_USER. `review_assignments.stage` is ADVISER or HEAD_LIBRARIAN; `research_works.current_status` is one of DRAFT, SUBMITTED, UNDER_ADVISER_REVIEW, UNDER_HEAD_LIBRARIAN_REVIEW, RETURNED_FOR_REVISION, REJECTED, ARCHIVED. Old rows from the retired roles/stages (PANEL, DEAN) stay in `reviews`/`status_history` as plain history text. No table structure changed, so no ALTER is needed; an existing database is brought up to date with `scripts\update_database.bat`.

## Manuscript alignment (Chapter 3)
- `roles` holds exactly five rows: STUDENT, FACULTY, LIBRARY_STAFF, ADMIN, EXTERNAL_USER. `users.is_head_librarian` (boolean, default false) designates the Head Librarian among Library Staff.
- `research_works.current_status` is DRAFT, PENDING_VERIFICATION, RETURNED or ARCHIVED. New columns: `dean_id` (FK users), `publication_status` (PUBLIC / RESTRICTED / UNPUBLISHED, set when archived), `archived_by` (FK users, the approving librarian). `program_id` is shown as **Course** in the interface. `category_id` is optional.
- `signatory_verifications` (new): verification_id, work_id, revision_number, verified_by, adviser_signed, panelists_signed, dean_signed, researchers_signed, sheet_complete, result (APPROVE / RETURN), remarks, verified_at. It replaces `review_assignments` and `reviews`, which are no longer used (existing rows are left in place for history).
- Upgrade an existing database with `scripts\update_database.bat` (calls `scripts\align_database_to_manuscript.py`): adds the columns, creates the table, moves ADVISER/PANELIST/DEAN users to FACULTY and HEAD_LIBRARIAN users to LIBRARY_STAFF with `is_head_librarian=1`, maps old statuses (SUBMITTED / UNDER_* -> PENDING_VERIFICATION, RETURNED_FOR_REVISION / REJECTED -> RETURNED), sets archived works to PUBLIC. It is idempotent and tested on a copy of the old schema (`server/tests/test_migration.py`).
