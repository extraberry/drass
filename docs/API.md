# API (all errors: `{"success": false, "error_code": "...", "message": "...", "fields": {...}}`)
Auth: `POST /auth/login`, `POST /auth/logout`, `GET|PATCH /auth/me`, `POST /auth/change-password`. Bearer token in `Authorization`.
Lookups/dashboard/notifications: `GET /lookups`, `GET /dashboard`, `GET /notifications`, `POST /notifications/{id}/read`, `POST /notifications/read-all`.
Submissions (STUDENT): `GET|POST /submissions`, `GET|PATCH /submissions/{id}`, `PUT /submissions/{id}/files/{MANUSCRIPT|SOURCE_CODE|VIDEO|OTHER_COMPANION}?filename=` (raw body), `POST /submissions/{id}/submit|resubmit`.
Verification (Library Staff; only the Head Librarian can POST): `GET /verifications/queue|history`, `GET /verifications/{work_id}`, `POST /verifications/{work_id}` body `{decision: APPROVE|RETURN, adviser_signed, panelists_signed, dean_signed, researchers_signed, sheet_complete, remarks, publication_status, expected_version}` - APPROVE needs all five items and archives the work; RETURN needs remarks.
Repository: `GET /repository` (filters program_id (course), department_id, year, adviser_id, dean_id, category_id, author, keyword; publication_status for Library Staff; sort; page; page_size), `GET /repository/{id}`, `PATCH /repository/{id}` (Library Staff: metadata), `PUT /repository/{id}/publication` (Library Staff), `GET /repository/{id}/companions/{file_id}` (Library Staff and the owning student).
Search: `POST /search/semantic`, `GET /recommendations/{id}`. Reader: `GET /reader/{id}/info`, `GET /reader/{id}/pages/{n}?scale=`.
Reports (ADMIN only): `GET /reports/{submissions|approvals|returns|pending-verification|archived|user-activity|system-activity}?format=csv`.
Admin: `GET|POST /users`, `PATCH /users/{id}`, `POST /users/{id}/activate|deactivate|reset-password`, `GET|PUT /admin/settings`, `GET|POST|PATCH /admin/lookups/{departments|programs|categories}`, `GET /admin/roles`, `GET /admin/indexing`, `POST /admin/indexing/rebuild`, `GET /audit-logs`, `GET /activity-logs`, `GET|POST /admin/backups`, `POST /admin/backups/restore` (`{name, confirm: "RESTORE"}`). The admin cannot call `/repository`, `/search/*` or `/reader/*`. Interactive docs at `/docs` when `ENABLE_DOCS=true`.

**Public (no login):** `GET /public/lookups`, `GET /public/repository`, `GET /public/repository/{id}`, `POST /public/search/semantic`, `GET /public/recommendations/{id}`, `GET /public/reader/{id}/info`, `GET /public/reader/{id}/pages/{n}?scale=` (read without an account; switch off with setting `guest_reading_enabled`), `GET /public/upload-limits` (size limit and accepted formats per kind of file) — ARCHIVED records only, rate-limited. `POST /auth/register-student` (student_number, last_name, username, email, password).
**Roster (ADMIN):** `GET|POST /admin/roster`, `POST /admin/roster/import` (`{"csv": "student_number,last_name,first_name,department\n..."}`).

**Integration API (X-API-Key, stable):** `GET /api/v1/ping`, `POST /api/v1/integration/roster`, `GET /api/v1/catalog/works`, `GET /api/v1/catalog/works/{id}` — see `docs/INTEGRATION.md`. **Key admin (ADMIN):** `GET|POST /admin/api-keys`, `POST /admin/api-keys/{id}/revoke`.

**Manuscript alignment:** `/reviews/*`, `POST /admin/works/{id}/override-approve` and `POST /submissions/{id}/panel` no longer exist. `GET /lookups` returns `faculty` (advisers and deans) and `publication_statuses` instead of `advisers`. Submission bodies take `dean_id`; `category_id` is optional. New settings: `max_source_code_mb`, `max_video_mb`, `guest_reading_enabled`; `semantic_threshold` default 0.25.
